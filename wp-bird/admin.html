Game settings

Shown on the menu screen of the game.

Flap keys

Keyboard keys that make the bird flap. The same keys also press Start on the menu and restart after a run, so one arcade button wired to any of these does everything. Touch and mouse always work too. N is reserved for the staff skip on the start screen. Press Add key, then hit the key on the keyboard or button box.

Bird skins

One image per brand. Every run the bird wears one of these at random and keeps it for the whole run; leave the gallery empty for the default bird. Every upload is made the same size: transparent margins are trimmed and the logo is fitted into a 512 × 512 square with even padding, so a wordmark with whitespace around it lands on the bird exactly as big as a tight square badge. Transparent PNGs look best. Click a tile or drop an image onto it.

Logo & mark

The logo is the menu hero above the title; the mark is the small brand logo under "Presented by". Transparent PNGs work best. Defaults come from the WP Gaming DigiCon 2026 deck.

How it works

  • Everything here is saved in this browser only. It is not uploaded anywhere.
  • Open the game from the same address (host and port) as this page, in the same browser, and it will use these skins.
  • To set up another device: Export here, copy the file over, then Import it in the admin on that device.
  • Images are resized to a maximum of 512px and stored as WebP (PNG where WebP is unavailable), keeping transparency.
  • The skin is picked when a run starts; a run already in progress keeps its bird. Gaps in the gallery are fine - only filled slots are used.
  • Reset to defaults deletes every uploaded image, the custom title, the flap keys and the bird choice.
